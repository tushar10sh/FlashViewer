How to use · Environment · Reference datasets · Conventions

1. How to use

  • Scope of a run. A full run executes Phases 1–12 top to bottom plus the cross-cutting scenario. A targeted run executes only the changed phase(s) plus that phase's Regression rows.
  • Marking. Set each scenario to PASS / FAIL / N/A (click a set button again to clear it). On FAIL, add a note, capture a screenshot + the exported log (ST-P1-6), and file an issue citing the ST- id. Fill the run header (build / tester / date) once.
  • Analysis-vs-display invariant. Wherever a step both reprojects for display and inspects a value, the inspected value must come from source pixels, never the warped display (FR-CRS-4 / FR-ACC-2). Do not "fix" a reported value to match the on-screen warped block.
  • ID scheme. ST-P<phase>-<n> functional; ST-P<phase>-R<n> regression. TC-ref links the matching automated case in TEST_SPEC.

2. Environment & build

Smoke tests are interactive (no QT_QPA_PLATFORM=offscreen). Build (Windows dev machine): enter the VS 2022 dev shell, conda activate flashviewer-windows, prepend the aqt Qt …\Qt\6.6.3\msvc2019_64\bin to PATH, then cmake --build build/windows-release --target FlashViewer → build/windows-release/FlashViewer.exe. Test steps are UI-level and apply on Linux/macOS too; only this preamble is Windows-specific. Help → About shows the version stamped from VERSION (FR-INST-4). Reset between phases with File → Close All; View → Panels → Reset Panel Layout (FR-APP-9) restores docks.

3. Reference datasets

Curated, free/open, mostly < ~200 MB, into a smoke-data/ folder. Some portals need a free account (USGS EarthExplorer, NASA Earthdata, Copernicus). Where a download is impractical, the synthetic FixtureFactory rasters (F-GRAD, F-CAT, F-CRSPAIR, F-NDVI, F-NODATA, F-MULTI — see TEST_SPEC §2) reproduce the same data characters.

4. Conventions

Each scenario shows Steps, Expected, Covers (primary FRs + SDD section + named incremental fix) and TC-ref. Unless stated, start from a freshly launched app with the dataset(s) named in Steps loaded.
